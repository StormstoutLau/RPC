## §2 任务卡契约（我生成的卡长这样）

```markdown
---
proj: paper
task: 蒸馏 <paper_id> 为三层分离 Skill
audit: true
model: nemotron
cli: opencode
sensitivity: public
readonly: false
timeout_s: 3600
continue-timeout-s: 1800
accept:
  - test -f out/skills/<id>_skills.md
  - test "$(grep -c '^## Skill' out/skills/<id>_skills.md)" -ge 2
  - grep -q '### Preconditions' out/skills/<id>_skills.md
  - grep -q '### Guarantees' out/skills/<id>_skills.md
  - grep -q '## 蒸馏统计' out/skills/<id>_skills.md
---
## 任务描述

**显式调用 `/paper-distill`**。

输入 `raw_md_full/<id>.md` → 输出 `out/skills/<id>_skills.md`。
分段读取（占用 <窗口 40%）；锚点回 `## Page N` 核对，宁标 [待核对] 不编造；
write 超时则用 bash heredoc 兜底；文末附「## 蒸馏统计」。

## 蒸馏专属判据（供 review --peer 判官读取）
1. 每个锚点可在 raw_md 对应页定位
2. 假设-结论对齐  3. 无编造定理编号/页码  4. 四节结构完整  5. 可执行性
```

**设计说明**：
- `audit: true` —— 依据 §5.4，触发 assertion-audit 断言契约
- **卡内无 `accept-golden`** —— 因 BC-1（`source` 只认框架仓根），详见 `01_DR-缺陷报告.md` §4
- `readonly: false` —— 蒸馏是写任务 → 排它锁 → 同站天然串行
- 判据用 `test … -ge 2` 而不用管道 `awk`（**假设 shell 为 bash**；若判据解释器不同请告知 → 见 §7 A3）
- 判据全部是**纯 shell 结构断言**（不依赖 Python/venv），避免环境门失败

## §3 敏感度与分轨（这是我最在意的合规点）

### 3.1 分轨规则

| 轨 | 判据（满足任一） | `sensitivity` | 期望的 wrapper 行为 |
|---|---|---|---|
| **轨 L** | 来源在 `D:\Article\` 下 / 无 DOI / 人工标记 | `local-only` | **拒绝任何远端路由** |
| **轨 P** | 非上述（已发表语料） | `public` | 默认仍给本地档；egress 仅作溢出 |

### 3.2 我的合规承诺

- 轨 L **绝不**请求 egress 档（且依赖 wrapper 的 `local-only + egress → REJECT exit 4` 硬门兜底）
- 轨 L 的抽检判官只用本地档（依赖 DR-2 修复，或用本地 http-local 判官）

### 3.3 本批 2468 篇的归属

`Paper_Organized_v2/` 的 2463 篇为**已发表论文** → **轨 P**。
用户未发表 Working paper（`D:\Article\`）**不在本批范围**（将来会单独立队列走轨 L）。

## §4 失败分类与重试矩阵（我按退出码的处置）

| exit | 我理解的语义 | 我的处置 | 消耗重试 |
|---|---|---|---|
| 0 | 成功 | 回收产物 → P2 | — |
| 2 | model 缺失/未知 / 卡语法错 | 修卡；若归因 DR-1 则挂 CR-3 并暂停泳道 | 否 |
| 3 | 锁占用 | 排队等待（视为正常状态） | 否 |
| 4 | 敏感冲突（local-only + egress） | 修模型档（**视为我方配置错误**） | 否 |
| 5 | ssh 断连 | 自动重试 1 | 否 |
| 6 | 超时（含 `timeout` 杀 124） | 依赖 `--continue` 续跑（≤2 轮，独立预算） | 是 |
| 7 | 免费档限额 | 切本地档重派 | 是 |
| 9 | accept 未达标 | 换站/换模型重蒸（≤2）→ 人工队列 | 是 |

> 上表是我从代码与手册**拼合**的理解，请确认权威清单（§7 A12）。

## §5 幂等与断点续跑

- 启动时扫描 `D:\Paper\agent-out/*/` 的 `.agent-run.json` → 构建 `done_set`
- 队列状态机：`pending → running → done | failed(n) | manual`
- 进程中断重启：跳过 `done`，`running` 视为失败重试
- 站上 `out/` 我**不清空**（依赖"单向流：`--sync` 永不覆盖 `out/`"这一不变量）
- 单篇产物按 `<id>` 命名（`out/skills/<id>_skills.md`），跨站/跨重试不冲突

## §6 抽检方式

| 项 | 我的做法 |
|---|---|
| 调用 | `agent-cli review paper --peer [--card <card.md>]` |
| 异源 | 依赖既有的「**产出方与审查方强制异站异构**」约定 |
| 抽样 | 随机 5% + 100% SUSPECT + 每泳道首篇 + 每 100 篇首篇 + 短文全检 |
| rubric | 用既有 `ops/station-bin/review/rubric-4level.txt`（五维 + 四级 + 6 幻觉标志） |
| 蒸馏专属判据 | **写在卡正文**（judge prompt 已含 `{{CARD_BODY}}`）→ 零代码改动 |
| 超时 | 期望设 `review-timeout-s: 900`（默认 600 恐不足：本地模型判 40K 产物） |
| 可复现 | 依赖 wrapper 内建的 `temperature=0` + `seed` + `prompt_hash` |
| 失败不阻塞 | `review_gate=false` 是既定语义，我按"记 `review_error` 转人工"处理 |

## §8 我不做的事（自我约束，避免越界/干扰）

- 不修改 `D:\RPC` 任何文件
- 不自行 ssh 执行框架操作（`infer-load`/`infer-unload`/配置改写/端口注入）
- 不绕过 `agent-cli` 直接调 `opencode` / `claude`
- 不在同一站内叠开并发（遵守跨站各 1 并发）
- 不使用 `decompose`（仅 readonly 支持）与 `isolate-xdg`（不解决带宽问题）
- 不在 `.agentsync` 中排除框架需要的任何路径
