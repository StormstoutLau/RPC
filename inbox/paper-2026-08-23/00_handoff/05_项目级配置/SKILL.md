# paper-distill — 论文 → 方法论 Skill 蒸馏

把一篇论文的全文 Markdown 转成**可执行、可机器检验、可回溯原文**的方法论 Skill。

---

## 输入契约

- **必须**是含 `## Page N` 分页标记的 raw_md（`N` = **物理页码**，不是刊物页码）
- 典型来源：`raw_md_full/<paper_id>.md`；Pilot 阶段在 `pilot_distill/raw_md/`
- 若文件含 NUL 字节（`\0`），先剥离再读，否则检索工具会误判为二进制

## 输出契约

- 单个 `.md`，默认落 `out/skills/<paper_id>_skills.md`
- **Skill 数 ≥ 2**（单篇论文通常 2–4 个可执行方法论）
- 每个 Skill 严格四节 + 首部三行元信息 ⬇

---

## 每个 Skill 的结构（严格模板）

```markdown
## Skill <字母>: <skill-name>

**触发条件**: <何时该用这个 Skill——具体到任务特征，不要写"需要分析数据时"> 
**来源**: <raw_md 文件名>
**维度**: 框架 / 案例

### Preconditions（形式化假设，可机器检验）

| ID | 谓词 | 来源 | 依赖 |
|----|------|------|------|
| H1 | <可判真假的陈述> | <论文, 节/式号, p.N> | — |
| A1 | <可判真假的陈述> | <论文, 节/式号, p.N> | H1 |

**编号规则（禁止重编号）**：
- 论文**有编号**的假设 → 沿用原编号（如 `Assumption 3.1`、`Condition A`、`(2.3)`）
- 论文**无编号**的结构性前提 → `H` 系列（H1, H2, …）
- **禁止**把论文原编号改写成自己的体系——那会切断回溯链

**谓词要求**：每条必须是**可判真假**的数学/逻辑陈述（"λ_t 为正" ✓；"模型合理" ✗）。

### 执行步骤

1. <动作>（用 H1, A1）
2. <动作>（用 A2）
…

**要求**：每步是**动作**（做什么），不是**摘要**（说了什么）；末尾标注该步用到的假设 ID。

### Guarantees（结论与公式锚点）

- <结论或公式> [<author><year>, <定理/式号>, p.<物理页>]
- …

**锚点格式**：`[作者年份, 定位符, p.物理页]`，定位符用论文原始编号（`Theorem 3.2` / `式(14)` / `§4.1`）。

### 边界限制

- <该 Skill 不适用的情形>

### Failure Modes（失效条件及后果链）

- 违反 <假设ID>（<具体情形>）→ <直接后果> → <补救动作或"无补救/模型类外">
```

---

## 反幻觉硬规则（IRON RULE）

1. **每个锚点写入前必须回 `## Page N` 核对**该页确有该定理/公式/式号。没核对过就不写。
2. **宁标 `[待核对]`，不可编造**。定位不到就显式写 `[待核对]`，并说明为什么（OCR 损坏/页码不明）。
3. **OCR 乱码处**：标注损坏 + 说明你如何验证（推导还原 / 交叉引用）。
4. **原文笔误**：以**编号式**为准 + 显式注明"原文式(x)疑为笔误，正确形式为…"。
5. **只写原文真实存在的内容**。不补充你自己的领域知识、不"补全"论文没给的结论。
6. **不把常识性技术当 Skill**（如通用矩匹配、标准 MLE）——除非论文给了该场景的特化形式。

## 自证要求

文末**必须**附：

```markdown
## 蒸馏统计
- Skill 数: <n>
- Preconditions 数: <n>
- 锚点数: <n>
- [待核对]: <n> 处（列出位置）
```

## 落盘兜底（重要）

若 `write` 工具超时或失败（本环境已实测出现）：**改用 bash heredoc 分块写入**：

```bash
mkdir -p out/skills
cat > out/skills/<id>_skills.md <<'EOF'
...第一块...
EOF
cat >> out/skills/<id>_skills.md <<'EOF'
...第二块...
EOF
wc -c out/skills/<id>_skills.md   # 自证已落盘
```

- 用 `<<'EOF'`（单引号）防止变量被 shell 展开
- UTF-8 无 BOM
- 写完必须 `wc -c` 报字节数

## 上下文纪律

- **分段读取**，不要一次性把全文载入上下文
- 上下文占用保持 **< 窗口 40%**（超窗口 30% 后模型注意力与输出质量均下降）
- 单篇任务控制在 20–30 轮内；不要跨论文续作（新论文 = 新会话）
