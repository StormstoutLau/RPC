## When to Run

- 每个研究阶段完成后，需要判断下一步行动
- 实验结果不达预期，需要决定是否调整方向
- 遇到研究瓶颈，需要评估是否回退或换思路
- 用户要求评估当前进展并给出建议

## Instructions

### 1. 收集当前状态

从各阶段产物中评估当前进展：

**检索已有产物：**
- `literature_review_*`：文献调研是否充分
- `baseline_result`：基线复现是否成功
- `research_idea`：创意是否明确
- `experiment_result`：实验是否验证假设
- `analysis_report`：分析是否完整
- `paper_draft`：论文是否成型

**检索决策历史：**
- 读取所有 `decision_record`，了解决策链
- 检查是否存在循环决策（重复回退到同一阶段）
- 评估累计投入的资源（时间、计算量）

### 2. 评估阶段成果

对当前阶段进行结构化评估：

```markdown
## 阶段评估：<当前阶段>

### 完成度
- [ ] 核心目标达成
- [ ] 产出质量达标
- [ ] 无遗留关键问题

### 质量指标
| 维度 | 评分(1-5) | 说明 |
|------|-----------|------|
| 完整性 | <s> | <说明> |
| 可靠性 | <s> | <说明> |
| 创新性 | <s> | <说明> |
| 可复现性 | <s> | <说明> |

### 关键问题
1. <问题描述及影响>
2. <问题描述及影响>
```

### 3. 决策判断

基于评估结果，在以下选项中决策：

**选项 A：继续推进（next_action = 下一阶段）**
- 条件：当前阶段目标达成，产出质量达标
- 行动：进入下一阶段

**选项 B：当前阶段迭代（next_action = 当前阶段）**
- 条件：核心目标未达成，但可修复
- 行动：补充工作后重新评估
- 限制：同一阶段最多迭代3次

**选项 C：回退到前一阶段（next_action = 前一阶段）**
- 条件：当前阶段的输入有问题（如基线选择错误、创意不可行）
- 行动：回退并修正前一阶段产出
- 限制：回退最多2个阶段

**选项 D：终止研究（next_action = finalize）**
- 条件（满足任一）：
  - 研究假设被实验否定且无替代方案
  - 累计迭代超过合理范围
  - 资源不足以继续
- 行动：整理已有成果，生成最终报告

### 4. 风险评估

对每个决策选项进行风险评估：

```markdown
## 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| <风险1> | 高/中/低 | 高/中/低 | <措施> |
| <风险2> | 高/中/低 | 高/中/低 | <措施> |
```

### 5. 记录决策

使用 decision_record 记录决策：

```
decision_record(
  stage="<当前阶段>",
  decision="<选择了哪个选项及具体行动>",
  rationale="<选择理由，基于评估数据和风险分析>",
  outcome="<当前阶段的关键成果摘要>",
  next_action="<下一阶段名称>"
)
```

**决策记录必须包含：**
- 明确的决策选项和选择
- 定量的评估数据支撑
- 风险评估
- 预期的下一步行动和时间估计

### 6. 更新研究图谱

使用 research_graph_update 更新研究状态：

```
research_graph_update(
  node_type="decision",
  node_id="decision_<阶段>_<序号>",
  status="completed",
  results="<决策摘要>",
  connections=[
    {"from": "<当前阶段>:<节点ID>", "relation": "evaluates"},
    {"to": "<下一阶段>", "relation": "proceeds_to"}
  ]
)
```

### 决策流程图

```
当前阶段完成
    │
    ▼
评估完成度 ─── 不达标 ─── 迭代次数 < 3? ─── 是 ──→ 迭代当前阶段
    │                                      │
   达标                                    否
    │                                      │
    ▼                                      ▼
评估质量 ─── 不达标 ─── 输入有问题? ─── 是 ──→ 回退前一阶段
    │                                      │
   达标                                    否
    │                                      │
    ▼                                      ▼
继续下一阶段                            终止研究 → finalize
```

### 输出格式要求

- 决策必须基于数据，不可凭直觉
- 评分使用 1-5 分制，附文字说明
- 风险评估必须包含缓解措施
- 迭代和回退次数必须跟踪，不可无限循环
- 终止决策必须充分论证
