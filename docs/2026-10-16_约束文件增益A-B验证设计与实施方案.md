## 0. 一屏结论

| 项 | 设计 |
|---|---|
| **验证目的** | 回答 **C-1**：把约束文件前置到 prompt 首槽，对**低幻觉**是否带来**可测增益**（从而决定是否落 W1 的 P1–P4） |
| **主指标（可机读）** | **编造引用率** = 生成引用中「经权威 API 核验**不存在**或元数据错误」的比例 —— 唯一硬指标，**自带外部判定器** |
| **副指标** | 仓内事实答错率 · 正确弃答率 / 过度弃答率 · 单题正确率 |
| **★ 关键设计** | **三臂**：`A` 对照（无约束）· `B` 处理（约束前置）· **`B'` 长度对照（等长无关文本前置）** —— 用于**分离「约束内容」与「单纯 prompt 变长」** |
| **判据（Go/No-Go）** | **Go** ⇔ `B` 对 `A` 主指标显著下降 **且** `B'` 对 `A` 不显著（否则归因给"长度"而非"约束"） |
| **零代码** | ★ 本轮**不需要 P1–P4**：约束注入只发生在**实验 prompt** 内（不改 `agent-cli.ps1`）⇒ **先验增益，再决定是否改代码** |
| **射程** | 结论**只对"该模型 × 该任务集"成立**（人格/约束效应**强模型依赖**，`2311.10054`）⇒ **不可外推**到其它模型 |

## 1. 假设与判据

| 项 | 内容 |
|---|---|
| **H1（备择）** | 约束文件前置会**降低编造率 / 提高正确弃答率**（相对 A） |
| **H0（零）** | 与 A 无差异 |
| **主判据（可机读）** | `编造引用率_B` 显著 < `编造引用率_A` |
| **拒真判据（关键）** | `编造引用率_B'` 与 `A` **无显著差异** ⇒ 否则"增益"来自**prompt 长度**，判 No-Go（约束无效） |
| **不做** | 不"部分采纳"、不降低判据迁就结论、不按显著性挑结果（预注册纪律） |

> **判定器必须先自证**（本仓 `rubric-blindspot` 纪律）：判据脚本要用**已知答案的合成样本**自测通过（正样本判"存在"、负样本判"不存在"）后，才能用于正式样本。

---

## 2. 三臂设计（★ 核心）

| 臂 | prompt 首槽 | 目的 |
|---|---|---|
| **A（对照）** | **空**（= 现状，无约束层） | 基线 |
| **B（处理）** | `constraints/quant-academic.md` 全文前置 | 测**约束内容**的效应 |
| **B'（长度对照）** | **等 token 的无关文本**（如等长的随机说明，**不含任何约束语义**） | 分离**长度效应** |

- **单变量原则**：三臂**仅差首槽内容**；模型 / 路由 / 温度 / `max_tokens` / 上下文 / 工作区 / 任务实例**全部冻结**。
- **顺序随机化 + 交错**：同一任务实例的 A/B/B' 三跑**随机顺序**执行，消除时序/热缓存效应。

---

## 3. 任务集（4 类，全部可自动判定）

| 类 | 任务形态 | 自动判定器 | 指标 |
|---|---|---|---|
| **T-REF** ★ 主指标 | 要求给出 **N 篇真实文献**（标题/作者/年/DOI） | **本仓已接入的 paper-search MCP**（`search_crossref` / `get_crossref_paper_by_doi` / `search_openalex`）批量核验**存在性 + 元数据一致性**（★ 判定外置，不受被验模型影响） | **编造引用率** · 元数据错误率 |
| **T-FACT** | 问**只有本仓文件才知道**的事实（如某配置表的行数、某常量取值） | 文件系统 + `grep` 自动比对真值 | 答错率 · 编造率 |
| **T-ABSTAIN** | 混入**不可答**问题（问/指向**不存在**的仓内文件或事实） | 真值已知（不存在） | **正确弃答率** · **过度弃答率**（对可答问题也弃答，`2401.13275` 的已知代价） |
| **T-MATH** | 有唯一解的**计量/数学**单题（可数值核对） | 数值比对 | 正确率 |

- **实例数（设计参数，可调）**：每类 **≥30 个独立实例**（**不是**同一 prompt 重复——温度/缓存会让重复无信息量）⇒ 每臂总计 **≥4×30 = 120 实例**。
- **任务集冻结**：实例在跑之前**生成并冻结哈希**（防事后挑选）；实例**不得**与约束文件的示例重合。

## 4. 混杂控制清单

| # | 混杂 | 控制 |
|---|---|---|
| 1 | **prompt 变长** | ★ **B' 长度对照臂**（见 §2） |
| 2 | 模型不可移植 | **声明射程**（§0）；如需外推须**换模型重跑** |
| 3 | **prompt cache 击穿**（E3 已知：改首槽⇒新前缀） | 每臂**独立 session**；记录 cache 命中与否；**成本按 cache-miss 计** |
| 4 | 顺序/热漂移 | **随机顺序、交错**（§2） |
| 5 | 判定器主观 | 判定器**自动 + 自证**（§1） |
| 6 | 采样噪声 | 配对设计 + **每实例多臂配对**；温度与 `seed` 显式记录 |
| 7 | 事后挑结论 | **预注册**：判据、任务集、实例数**先冻结**再跑 |
| 8 | 上下文长度不齐 | 三臂**同 max_tokens、同 ctx**；长度差**只在首槽**且被 B' 对照 |

## 5. 执行通道（复用既有资产，**零代码改动**）

- **不新增脚本、不改 `agent-cli.ps1`**（ADR-0004 D2）——实验直接打**引擎 API**：
  - **本地档**（推荐，成本≈电+时间）：`ops/cluster.py load <alias> --engine <ver>` → `POST /v1/chat/completions`（口径同 [metrics-log Phase 9](../spec/rpc-optimization/metrics-log.md)：随机化 prompt、防 prefix cache）。
  - **云档**（若需更强模型）：走既有 provider 凭据面（`cluster.py providers`）。
- **核对器**：paper-search MCP（§3 T-REF）+ 文件系统/grep（T-FACT）+ 数值比对（T-MATH）。
- **记录口径**：沿用 metrics-log 的 A/B 表（每臂指标 + Δ + 每实例明细落盘）。

## 6. 判据（Go / No-Go）

- **Go（值得落 P1–P4）**：`B` 相对 `A` **主指标显著下降**，且 `B'` 相对 `A` **不显著**，且**过度弃答率不显著上升**（否则是"更保守"而非"更准"）。
- **No-Go（约束无效）**：`B ≈ A`，或 `B ≈ B'`（⇒ 效应归因"长度"）⇒ 记录 **"约束文件对本形态无增益"**，W1 降级为**可选**，**不改 `agent-cli.ps1`**。
- **弱条件（记录待判）**：副指标改善而主指标无变化 ⇒ 记入 metrics-log，**是否落地交 Scott 决策**。
- **统计法**：配对二值指标用 **McNemar / 符号检验**；连续指标用**配对 bootstrap CI**。★ **不预设效应量**，判据结构如上（Go 需"显著 + 对照臂不显著"双条件）。

## 7. 射程与未确证（如实）

- **射程**：结论**只对该次所用模型 × 该任务集**成立；**人格/约束效应强模型依赖**（`2311.10054` 显示最优角色≈随机、跨模型不可预测）⇒ **不得外推**到云档或其它本地档。
- **未确证**：① 本框架任务集上约束的真实效应**完全未知**（§3.5 全为 E3）；② `B'` 等长无关文本的**构造**可能仍带轻微语义（须人工复核其"无约束语义"）；③ 判定器 API（Crossref/OpenAlex）对**中文/预印本**覆盖不全，可能把"漏检"误判为"编造" ⇒ 须**双向复核**（漏检率单独报）。
- **风险**：约束文件使 `B` 臂 prompt 变长 ⇒ **成本上升 + cache 击穿**，须与增益**同框比较**（否则"有效但贵"被写成"有效"）。
