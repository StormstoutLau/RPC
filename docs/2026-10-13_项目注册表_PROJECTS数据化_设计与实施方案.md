## 2. 设计（四条写死的决策）

### D1 · `id` = **现行键逐字**（兼容承重）
`id` 必须与 2026-09-23 的硬编码**逐字相同**（`paper` / `Cpp_Hub` / `Auto_Prover` / `dogfood`）。
**理由**：`id` 是**调用方实参**（`agent-cli <cmd> <id>`）**兼站上工作区目录名** ⇒ 任何归一/改造会破坏
**所有既有调用点**与既有工作区。★ 这与 `namespaces.yaml`（id 取小写规范名）**不同**，因为那是**身份轴**、这是**调用轴**。

### D2 · 读路 = **判据侧吐 JSON**，外壳**不自己解析 YAML**
PowerShell 5.1 **无 YAML 解析器**。若外壳自解析 ⇒ **两个解析器**（PS 手写 + 门禁 `yaml.safe_load`）
⇒ 格式漂移即 **fail-open/假绿**（本仓头号形态）。⇒ 走 **F4 既有壳**：`py ops/rpc_check.py --list-projects`（JSON）。
★ 与铁律「外壳不重写判据、共用同一实现」同源。

### D3 · 判据**不判 `root` 存在性**
`F:`/`E:` 为**外盘**，可能离线 ⇒ 判存在性会**假红**（同 `namespaces` 只判形态的原则）。
⇒ 只判 `root` **非空字符串**；**存在性**由 `workspace create` 的 `Test-Path`（L543）在**使用时**判（**使用时报错**，胜于**门禁常红**）。

### D4 · 载入失败 ⇒ **fail-closed，不回退硬编码**
载入失败（缺 `py` / 判据非 0 / 输出空）⇒ `$Script:PROJECTS = @{}` + `$Script:PROJECTS_ERR` 记因。
★ **绝不**回退到硬编码常量（回退 = **第二份真值**，正是本方案要消灭的东西）。
后果：命令侧本就有 `(registered: $($Script:PROJECTS.Keys -join ','))` ⇒ 会如实打印 `(registered: )`（**可见的"没载入"**）。

## 3. 接口定义

### 3.1 真值 `inventory/projects.yaml`
```yaml
version: 1
updated: 2026-10-13
owner: Scott (鹏)
projects:
  - {id: paper,       label: Paper,       root: 'D:\Paper',              status: active, since: 2026-09-14}
  - {id: Cpp_Hub,     label: Cpp_Hub,     root: 'F:\Cpp_Hub',            status: active, since: 2026-09-14}
  - {id: Auto_Prover, label: Auto_Prover, root: 'F:\Auto_Prover',        status: active, since: 2026-09-14}
  - {id: dogfood,     label: dogfood,     root: 'd:\RPC\tmp\dogfood-ws', status: active, since: 2026-09-23}
```

### 3.2 判据面（`ops/rpc_check.py`）
| 名字 | 签名 | 职责 |
|---|---|---|
| `PROJ_STATUS` | 常量 | `("active","retired")` 闭集 |
| `PROJECTS_REG` | 常量 | `ROOT/"inventory"/"projects.yaml"` |
| `validate_projects(reg)` | 纯函数 → `(bad, notes)` | 自洽：id 非空 / status 闭集 / since 形 / root 非空 / **同一串不许属两条** |
| `projects_index(reg)` | 纯函数 → `{id: root}` | **只收 `active`**（消费面：外壳载入 · `--list-projects`） |
| `check_projects(ctx)` | 断言 → `(status,note,detail)` | 门禁 `projects`（缺 yaml ⇒ FAIL；不自洽 ⇒ FAIL；否则 PASS） |
| CLI `--list-projects` | 早返回 | 打 **JSON**（`projects_index`）；不自洽 ⇒ exit 2 |

### 3.3 外壳载入（`agent-cli.ps1`）
L44 声明空表 → **L53 之后**（`REPO_ROOT` 已定义）INIT 块：调 `--list-projects` → `ConvertFrom-Json` → 填表。

   **整仓 sync**（可能 GB 级 ⇒ 冲爆 temp/站上盘）= **登记即制造可被触发的 footgun**。
   ⇒ `ONB-2` 与步 ②（`.agentsync`）**必须同批** ⇒ **推迟为下一批**（§7 末行）。
