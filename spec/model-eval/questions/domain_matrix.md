## A. 相依结构与定价算子的脆弱性（copula / 算子传导）

### A1. 相依性参数空间上的定价脆弱性拐点 `[概念] `准入
- **考查目标**: 能否把"绝对导数有限"与"相对灵敏度爆炸"分离，识别真正的脆弱性机制（v1.1 审查修正: 原稿"有效灵敏度"未定义，不可判分）。
- **前置概念**: 设夹层保费泛函 Φ_k(ρ) 连续依赖单参数相关性 ρ∈(-1,1)（k 为夹层序号）。定义
  **绝对灵敏度** = |Φ_k′(ρ)|，**相对（有效）灵敏度** S_k(ρ) = |d ln Φ_k(ρ)/dρ| = |Φ_k′(ρ)/Φ_k(ρ)|。
  两者可量级悬殊——当支付本身趋小时（小分母效应），S 可以任意大而导数保持有限。
- **应用对象**: t-copula 相关参数 ρ 驱动的 CDO 高级夹层（senior tranche，期望损失小）保费 Φ_senior。
- **任务·分步**:
  1. 构造一个例子说明: Φ′(ρ*) 有限而 S(ρ*) 可以任意大（提示: 支付概率/期望趋小的夹层）。
  2. 判断: ρ→1 且 ν 固定时, senior 层的 S 是否系统性放大? 用 t-copula 尾部测度正则性论证（不算闭式）。
- **输入/输出**: ≤10 行；每步一个明确结论。
- **判分锚点**: ① 小分母机制（相对 vs 绝对灵敏度）清晰可操作；② 尾部正则性切入而非口号。
- **疑似幻觉标志**: 断言"绝对导数必发散"；或称"相对灵敏度恒等于绝对灵敏度"而无小分母论证。

### A2. CDO 定价算子的 Fréchet 可微性 `[证明] `深度
- **考查目标**: Fréchet/Gâteaux 区分 → 分层证明（先识别线性层，再攻参数链）→ 对"算子范数发散"命题的批判。
- **前置概念**: Banach 空间 (X,‖·‖) 上 F:U→ℝ 在 x 处 **Fréchet 可微**: 存在有界线性泛函 DF(x)，F(x+h)−F(x)=DF(x)h+o(‖h‖)。Gâteaux 可微只要求方向导数，不要求余项一致为 o(‖h‖)。
- **应用对象（两层结构, v1.1 审查修正: 原单层定义对 C 线性, 使可微性平凡且发散问题不适定）**:
  - **L1（测度层）**: Φ(C) = ∫_{[0,1]^n} g(z) dC(z)，g(z)=L_tranche(∑_i w_i·1{z_i≤p_i}) 为有界分段线性夹层支付，C 为 copula 测度（范数取 TV）。
  - **L2（参数链）**: Φ(θ) = ∫ g dC_θ，θ=(ρ,ν) 为 t-copula 参数。
- **任务·分步**:
  1. 用自己话解释 Fréchet vs Gâteaux 差异。
  2. 证明 L1 的 Fréchet 可微性并写出 DΦ 是什么。**显式指出 L1 的线性结构**（识别到"Φ 对 C 线性 ⇒ DΦ 与 C 无关"者为高分——多数答卷会忽略此点）。
  3. 【深度】真正的非平凡可微性在 L2: 给出 ∂Φ/∂ρ 存在的充分条件（密度光滑性 + 控制收敛），并判断 ‖D_θΦ‖ 何时发散——高斯 vs t(ν=4) 哪个更可能因密度导数的 L¹ 行为在尾部出问题。给判断与理由。
- **输入/输出**: 分步作答；最终 ≤3 行结论。
- **判分锚点**: L1 用 *g 有界 → 线性泛函 TV 连续 → 平凡可微* 且明示线性；L2 链含 *∂_ρ c_θ 存在 + 控制收敛*；发散命题落回**密度导数的可积性**而非泛函本身。
- **疑似幻觉标志**: 在 L1 上声称"非线性所以难证"（忽略线性性）；在 L2 无支配收敛/可积性条件就断言发散与否。

### A3. 匹配秩相关下高斯与 t-copula 的尾部行为 `[计算] `准入
- **考查目标**: 椭圆 copula 的 Kendall τ 不变性（与 ν 无关）→ 尾相依才是两族差异源；数值 + 机制双测。
- **前置概念**: 对**一切椭圆 copula（含高斯与 t）**，总体 Kendall τ = (2/π)arcsin ρ——**与 ν 无关**（经典结果，尾结构不改变 concordance）。两族的真正差异在**尾相依**: 高斯 λ_U=0；t(ν) 的 λ_U = 2·t_{ν+1}(−√((ν+1)(1−ρ)/(1+ρ))) > 0。
- **应用对象**: 目标 τ₀=0.5，分别配高斯与 t(ν=4) copula 驱动 CDO 夹层。
- **任务·分步**:
  1. 解出两者的 ρ 并指出它们的关系（应相同——若答不同，说明踩了椭圆族 τ 不变性的坑）。
  2. 【深度】解释: 尽管两者 (ρ, τ) 完全一致，为何 senior 夹层价格与其 ρ-灵敏度仍系统性不同（用尾相依 λ 机制）；并指出"匹配 τ ⇒ 匹配尾部风险"这一直觉错在哪。
- **输入/输出**: 数值 + ≤6 行机制说明。
- **判分锚点**: ρ = sin(π/4) ≈ 0.7071 ✓ 且明示两族相同；尾相依 λ 公式/方向正确；senior 层机制（尾部质量 → 极端损失联合概率）成立。
- **疑似幻觉标志**: 声称"同 τ 下 t 的 ρ 系统性更小/更大"（椭圆族 τ 与 ν 无关——此为 v1.0 原稿自身的事实错误，已修正并转为陷阱）。

## B. Heston 与波动率曲面

### B1. Heston 特征函数的 Riccati ODE `[证明] `深度
- **考查目标**: Feynman–Kac → Riccati 结构 → 线性化误差定性。
- **前置概念**: Feynman–Kac 把 SDE 期望转 PDE/ODE。Heston: dS/S=r dt+√v dW¹, dv=κ(θ−v)dt+σ√v dW², ⟨dW¹,dW²⟩=ρdt。特征函数 φ=e^{A+B v₀}, B 满足 Riccati。
- **任务·分步**:
  1. 解释 Feynman–Kac 与风险中性定价的关系。
  2. 写 B 的 Riccati 标准形 dB/dτ=αB²+βB+γ，标出二次项系数来自 σ。
  3. 【深度】丢弃 αB²（线性化）的定价误差首项在哪；是否等价于"v 常数"。
- **判分锚点**: 二次项/漂移系数分配正确；线性化误差定性对；不把 Riccati 写成线性。
- **疑似幻觉标志**: 二次项系数 α=σ²/2 被误置于漂移项或写成 σ（量纲错）；把 Riccati 当线性 ODE。

### B2. 短期斜率与套利诊断 `[计算] `准入
- **考查目标**: 隐波曲面短期行为的阶数估算 + 套利根因三选一（Feller vs strike 域 vs 传导断裂）。
- **前置概念**: Heston 短到期 ATM 隐波偏斜经典极限: ∂σ_imp/∂k|_ATM → **ρσ/4**（T→0，每单位 log-moneyness；符号由 ρ 定）；Feller 条件 2κθ ≥ σ² 保证 v 不触 0。
- **应用对象**: Heston 拟合曲面在短到期（T=0.05）出现 DITM 侧负微笑/局部负 vega 域。
- **任务·分步**:
  1. 写出短期 ATM 斜率极限公式并给符号/量级判读（由 ρ 定符号；数量级即可）。
  2. 必三根因逐一给判别讯据（过程 t=0 到达概率 vs strike 宽域 vs 曲面自洽性），判定选一。
- **判分锚点**: 三判据可区分；不把 Feller 违反当唯一答案。
- **疑似幻觉标志**: 断言"负微笑必为套利/必为数值误差"等一刀切。

## C. 最优执行（Avellaneda–Lipkin 型）

### C1. 市场影响与最优执行路径 `[概念] `准入
- **考查目标**: 时变/影响函数概念迁移；不贴标签。
- **前置概念**: 最优执行最小化 影响成本+库存风险；影响函数 ρ(v)=γ|v|（临时）+ 永久项不随 v 方向。
- **应用对象**: 单资产线性影响 + 幂罚项 ρ(v)=Γ|v|^p, p∈[1,2]。
- **任务·分步**:
  1. 解释 p=1 (线性) vs p=2 (二次)最优路径在起点/终点边际的差异。
  2. 说明纯线性暂时性影响下总影响成本 γ∫|v|dt = γ·X 与交易日程无关（**日程不变性**），此时最优形状由库存/风险项单独决定（角点解倾向）；而二次影响才给出内点平滑路径——指出这如何反驳"最优执行=匀速"的直觉。
- **判分锚点**: 线性影响的日程不变性被识别；角点 vs 内点对照正确；避免"只答 VWAP/匀速"。
- **疑似幻觉标志**: 称"最优执行=匀速"而无库存项论证（LeBaron 弹簧的浅答案）。

### C2. 数值最优执行路径 `[代码] `准入
- **考查目标**: 离散化 + 边界 + 一阶条件。
- **前置概念**: 连续时间 OCP 用欧拉/庞特里亚金；终条件 v(T)→x_T（清仓约束）。
- **应用对象**: 单资产, 影响 Γ|v|², 库存惩罚 λ x², T 期清仓。
- **任务·分步**: 写一段(伪)Python 求最优交易速度序列 v(t)。要求: 边界 v 在 T 满足清仓、目标函数离散正确、可沙箱运行。
- **判分锚点**: 目标离散正确（二次影响+库存）；边界 v(T)→清偿；数值收敛。
- **疑似幻觉标志**: 代码混用/缺失清仓边界而自称解。

## D. 混频因果（MIDAS–Granger 型）

### D1. 权重聚合的一致性与谱混叠 `[概念·计算] `准入
- **考查目标**: 估计一致性 → 谱域畸变。
- **前置概念**: MIDAS 用参数化权重 w(j,ω) 把高频 {x_{t/k}} 聚到低频 y_t；等权平均是特例。
- **应用对象**: 日频 x → 月频 y 的回归。
- **任务·分步**:
  1. 解释等权逐窗平均为何引入谱折叠/旁瓣，参数化 β-Lag 权重如何减小（平滑/单峰）。
  2. 给一个具体权重（如 Almon 2 参）并说明自由度为何更省。
- **判分锚点**: 命中旁瓣/混叠；权重单峰平滑；自由度论证。
- **疑似幻觉标志**: 称"等权最优"或"权重项越多越好"（过拟合）。

### D2. 前视泄漏与因果方向排查 `[诊断] `深度
- **考查目标**: 因果识别中的泄漏源 + 可证伪方向。
- **前置概念**: Granger 因果需时序因果顺序；聚合窗口若含未来值=数据前视。
- **应用对象**: 某实现报"高频→低频 Granger 显著"。
- **任务·分步**:
  1. 设计一个会造成前视泄漏的错误抽样；给出修复。
  2. 论断: 权重多项式本身是否系统性偏差低因果方向识别？给理由与一个判别（如滞后阶跨越边界）。
- **判分锚点**: 精确定位"落在低频观测时点之后的窗口=泄漏"；对方向偏差给严谨证据（聚合非线性/低频混叠）。
- **疑似幻觉标志**: 泛泛"可能有过拟合"而无前视/边界判据。

## E. 因子失效与矩条件诊断

### E1. 因子样本内外失效的机制区分 `[诊断] `准入
- **考查目标**: 反事实验证。
- **前置概念**: 样本内显著样本外失效的机制: 数据挖掘/多重比较、因子拥挤（交易成本吃掉）、结构性断裂、定价核变化。
- **应用对象**: 某价值/动量混合因子回测。
- **任务·分步**: 列至少 3 机制并各给一个区判检验（可拆分样本、到位成本回撤、断点检验、SDF 换核敏感性）。
- **判分锚点**: 机制离散且检验可区分；不只是"过拟合"。
- **疑似幻觉标志**: 把"失效"全归于过拟合（缺拥挤/断裂分支）。

### E2. 矩条件局部误设定下的 GMM 权重敏感度 `[证明] `深度
- **考查目标**: GMM 权重矩阵作用 → 局部识别。
- **前置概念**: 两步 GMM 最优权重 W=S⁻¹（S=E[gg′] 为矩协方差）；局部误设定时，逆方差权重会给"方差小但偏置大"的矩更高权重。
- **应用对象**: 因子定价矩条件 E[R-βΛ]=0 在某资产子集上轻微失效。
- **任务·分步**:
  1. 说明最优权重为何给"方差小但偏置大"的矩更高权重，使局部误设定的影响被放大。
  2. 提出正则化（收缩/分数加权）修正，并说明代价。
- **判分锚点**: 权重与矩方差-偏置的权衡；正则化代价明确。
- **疑似幻觉标志**: 称"最优权重自动稳健"（需 hausman 式稳健性才成立）。

## G. 宏观与资产配置

### G1. Epstein–Zin 递归效用与长期风险 `[概念] `准入
- **考查目标**: 偏好分解 → 资产定价含义。
- **前置概念**: EZ: U_t = [(1−β)C^{1−1/ψ}+ β(E_t[U^{1−γ}])^{(1−1/ψ)/(1−γ)}]^{1/(1−1/ψ)}；IES ψ 与风险厌恶 γ 分离。
- **应用对象**: 用 CRRA 与 EZ 各定价一个市场组合股利。
- **任务·分步**: 解释两者对"长期增长风险 vs 短期风险"的价差差异；说明为何 EZ 需要 ψ≠1/γ 才拉开风险价格。
- **判分锚点**: IES/γ 分离 → 远期/波动率价格；避免只答"更高偏好折现率"。
- **疑似幻觉标志**: 把 EZ 误写成可加偏好或 ψ=γ 恒等。

### G2. regime 平滑化对尾险的低估 `[诊断] `深度
- **考查目标**: 状态估计与定价的耦合批判。
- **前置概念**: MS/马尔可夫切换下回归的滤波/平滑化概率；状态依赖的随机折现因子 SDF。
- **应用对象**: 两机制（高/低波动）DSGE，用平滑后 regime 概率做 SDF 权重。
- **任务·分步**: 论证"对 regime 概率做后向平滑或用过度平滑先验"会系统性压低对快切换尾险的定价；给一个常数/识别判别检验。
- **判分锚点**: 链接滤波 vs 平滑、快切换、状态依赖定价；判别可操作。
- **疑似幻觉标志**: 称"平滑化无偏"（后向平滑引入滞后偏置）。

## H. 行为对齐与叙事因果

### H1. 行为-意见对齐与时序泄漏防护 `[概念] `准入
- **考查目标**: 预测-行为一致性 meta 概念 + 泄漏。
- **前置概念**: 对同一事实，模型/信号的两类表达（行为 vs 意见）应一致；训练/评估中信息不得来自未来。

- **疑似幻觉标志**: 以为对齐=相关，而未提时点因果。

### H2. 叙事传播对预测的可证伪性 `[诊断] `深度

- **判分锚点**: 用到滞后方差分解/条件独立/工具；不满足于 Granger 显著。
- **疑似幻觉标志**: 把 Granger 显著直接当因果。

## I. 形式化验证

### I1. 三层验证器的错误覆盖 `[概念] `准入
- **考查目标**: 验证分层职责。
- **前置概念**: 数值区间验证（数值界）、SMT（可解逻辑一致）、形式系统（构造正确性/依赖图）。
- **应用对象**: 一个 CDO 定价数值结论。
- **任务·分步**: 各举一个会被该层捕获而其它层漏过的错误。
- **判分锚点**: 三类错误命中（浮点界数/逻辑矛盾/前提漏载）。
- **疑似幻觉标志**: 三层职责重叠混淆。

### I2. 单调反函数的构造性证明 `[证明] `深度
- **考查目标**: 构造完备性 vs 存在性。
- **前置概念**: 反函数定理/单调连续+严格单调即有连续反（构造依赖 **ℝ 完备性**——区间二分；不依赖选择公理）。
- **应用对象**: 目标: 对 f:R→R 连续严格单调，证 f 有连续反。
- **任务·分步**: 给出构造性证明或明确说明哪一步依赖非构造选择（区间二分+完备性即可构造）；并指出"存在性 vs 可构造计算反"的差距。
- **判分锚点**: 二分构造链完整；诚实标注选择/完备性依赖。
- **疑似幻觉标志**: 跳过二分直接引用反函数定理而不给出构造依据。

## J. 跨领域综合

### J1. 因子验证方法论（四重路径） `[诊断] `深度
- **考查目标**: 完整验证流水线 + 优先序。
- **前置概念**: 数据泄露、正交性/冗余、样本外健壮、经济机制（贴近优先）。
- **应用对象**: 一个被报告显著的因子。
- **任务·分步**: 设计验证顺序，并说明为何"数据泄露检查放最前"。给每步一个最小失败判据。
- **判分锚点**: 顺序正确 + 判据可执行（非口号）。
- **疑似幻觉标志**: 无泄漏检查即宣称显著。

### J2. 敏感度、脆弱性与统计可辨识的对偶 `[概念] `深度
- **考查目标**: 泛函敏感度与 Fisher 信息链接；识别脆弱的统一观。
- **前置概念**: 参数敏感度=导数/算子范数；可辨识下限由 Fisher 信息（Cramér–Rao）给出。
- **应用对象**: 一个定价模型对参数 θ 的输出 F(θ)。
- **任务·分步**:
  1. 论证"高敏感度（**相对条件数大**: ‖∂F/∂θ‖·‖θ‖/‖F‖）"与"低可辨识（小 Fisher 信息）"如何耦合使一个模型"既脆弱又难校准"。
  2. 给一个你构造的尺标(基于导数与信息量的比)来量这种"结构性脆弱"，并说明能摆脱单纯参数的信号。
- **判分锚点**: 耦合论证 (导数×信息量)；构造粗糙但方向可辩护。
- **疑似幻觉标志**: 把敏感度必当脆弱 / 把 Fisher 大必当稳健。
