### 区分度结论 (B6 体系首证)

1. **同套件成功分离两模型行为**: qwen3.8-flash-next (thinking 分离 + 预算可控) vs m27 (思考/正文混杂 + 长输出失控) — 差异不是"谁更聪明"而是**推理预算管理能力**, 这正是 agent 场景的关键质量维度
2. **thinking 分离是架构级差异**: qwen (qwen4exp) 有 reasoning\_content 独立通道, m27 (MiniMax M2.7) 无 — 前者禁思考即真禁, 后者禁思考只改输出形态, 预算问题依旧
3. **数值/概念题两模型质量相当** (B2/A1 持平), 深度题 qwen 略优 (G1 SDF 分解)
4. **吞吐**: m27 thinking 19.7 t/s vs qwen 15.7 t/s, 但 m27 不可控性抵消速度优势

### 基础设施追加发现 (回填 DESIGN)

1. **m27 型 (无 reasoning 分离) 模型**: 数值题禁思考 + 2048 仍可能零产出 (输出前置思考) — 需按模型分型, 不能只按题型; A3 型短数值题对这类模型或需 3 次采样取首次含 ANSWER 行
2. **看门狗必要性实锤**: 长生成任务挂 A 站风险真实存在 (KFD bug 族), 20s ping + 3 失败自动止损应成为 b6\_run\_eval.py 标配
3. **Beszel CPU 告警已加** (两站 95%/3min) — 挂死前兆 (workqueue hogged) 的可用近似监测
