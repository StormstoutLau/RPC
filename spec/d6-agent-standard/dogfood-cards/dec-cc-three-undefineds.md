## 任务描述

**背景（抽象）**：一个研究仓库定义了一份**结论契约** —— N 个"判官"对同一份被审对象各出一份**结构化意见**，
再由一个**综合器**把它们分类成「共识 / 分歧 / 孤例」。该契约已落成校验器与综合器（纯函数），
但**只在离线夹具上跑过**，真调用未跑。

**契约形状（机器可读，逐字给）**：

```json
{
  "verdict": "accept | revise | reject | uncertain",
  "findings": [
    { "id": "F1", "statement": "一句话（可被逐条核验）", "hit": true, "priority": 3,
      "confidence": 0.8, "path": "某文件相对路径", "line_range": "L120-L134", "note": "可选" }
  ],
  "score": "优秀|良好|合格|不合格",
  "pass": true,
  "conclusion": "一段结论"
}
```

**逐字段硬约束（校验器判的就是这些）**：

| 字段 | 约束 | 为什么 |
|---|---|---|
| `verdict` | **封闭枚举**四选一 | "受限判定"⇒ 可数、可对账 |
| `priority` | **整数**（≥0） | 浮点会让"排序"变成"看起来有区别" |
| `confidence` | **浮点**，`0.0 ≤ c ≤ 1.0`；**越界 = 无效** | 概率语义（不许 1.5 或 `"high"`） |
| `hit` | **布尔**（true = 该锚点**达标**） | ★ **有它才使"分歧"可判**（同一位置两人判反） |
| `path` | 必填，非空 | 意见必须落到**一个具体文件** |
| `line_range` | 必填，形如 `L<起>-L<止>`（单行 `L<n>` 允许；`L<起>-` 允许） | **落不到行的意见不可核验** |
| `agreement` | ★★ **单个判官【不得】输出此字段** | 它由**综合阶段**算出；判官自报 = **自证**（本仓库禁止）。校验器见到 ⇒ **拒** |

`agreement` 值域（**只由综合器产出**）：`consensus` · `disagreement` · `unique`

**综合规则**：以 **`path` + `line_range`**（**归一化后**，**不含 `statement`**）把各判官意见对齐成"锚点"。
★ **为什么锚点里不含措辞**：不同判官对同一件事的表述必然不同 ⇒ 若把措辞并入键，"共识"会**几乎永不出现**
（分类随即退化成噪声）。**位置是客观的，措辞不是** ⇒ 用位置对齐。

| 分类 | 判定 |
|---|---|
| `consensus` | 该锚点被 **≥2 个判官**提到，且**所有 `hit` 一致** |
| `disagreement` | 该锚点被 **≥2 个判官**提到，且 **`hit` 不一致** |
| `unique` | 该锚点**只被 1 个判官**提到 |

另有**两条硬纪律**（否则分类会变成假信号）：
1. **单判官 ⇒ 只可能是 `unique`**，且**必须同时报 `judges=1`** —— 不许把"只有一个判官"渲染成"多家共识"；
2. **空集不产共识**：`findings` 为空时 `consensus` **必须为空**（`0/0` 读成"没问题"是该仓库已登记过的假绿形态）
   ⇒ 综合器**必须**把输入规模（判官数 / 意见数）**显式报出来**。

### 现在要你分析的**三条**（文档自认"未定"，逐条给原文要点）

**① `path` 的相对根未定义** —— 契约要求 `path` 必填，但**没规定它相对谁**
（运行目录 / 项目根 / 仓库根）。文档**自认这是本契约最大的未定项**。

**② `line_range` 越界未校验** —— 校验器目前**只校形态**（`L<起>-L<止>`），
**不校是否超出该文件的实际行数**；而「**越界即无效**」这条**也未裁**。
⚠ **已知代价**：若升级为"越界即无效"，校验器就**必须去读被审文件本身**
（当前它是**纯函数、只吃字符串**）⇒ 会把一个纯函数变成一个**需要文件访问**的函数。

**③ 三分类阈值「≥2 = 共识」未经任何验证** —— 该数值是从**另一个用途**（多模型辩论的质量收益）推来的
**设计选择**，本仓库**没有实测支撑**。

### 唯一产物：`out/dec-cc.md`

**格式（小节名照抄、顺序照抄）**：

1. `## 事实认定` —— 这三条**各自到底是什么性质的问题**？逐条（每条一行 `- `）写：
   你认定的事实 / 依据（上面哪一条）/ 还不确定的。必须逐条回答：
   它是「**缺规格**」（没定义）·「**缺判据**」（定义了但没机判）· 还是「**缺依据**」（有判据但无实测支撑）——三选一并给理由。
2. `## 候选处置` —— 对**三条分别**穷尽列出可选动作（**合计 ≥8 条**），每条一行：
   `对象 | 动作 | 适用条件 | 它避免了什么 | 它引入了什么代价 | 可逆性（可逆 / 不可逆）`。
   ★ 三条里**至少各有一条**是"**什么都不做并写下理由**"。
   ★ `②` 的候选里必须显式含"**保持纯函数、把越界降为警告**"与"**改为读文件、越界即无效**"两种，并写清代价差别。
3. `## 决策` —— 对**三条分别**选一个或一个组合，每条写：
   ① 为什么（不要只说"稳妥"）；② **它在什么情况下应被推翻**（反转条件，要**可判**）；
   ③ ⚠ **它会不会把真信号洗掉**（例：把"越界"从无效降为警告，会不会让**真错误**静默通过？必须显式说明如何避免）。
4. `## 可执行步骤` —— **有序**清单（每条一行 `- `），每步写：
   动作 / 期望输出 / 判据（看到什么算过）/ 不过怎么办。
   要求：**先取证、再判定、最后才改判据**；并写明"**改判据之前必须先留下什么记录**"。
5. `## 验收判据` —— 可机判形态 ≥5 条（每条一行 `- `）：`看到 X ⇒ 判 Y`。
   **至少含两条反向**判据（"若出现 Z ⇒ **必须判不通过**"）。
6. `## 不确定项` —— 你无法从上述材料判定的，逐条说明缺什么（**不许猜**）。
