## 任务描述

**输入 = 随本卡提供的附件**：一份**已人工脱敏**的分界判据摘要（工作区 `.attach/` 下唯一的那份 `.md`）。
它是某个决策文档里"判据 + 归属 + 理由"三节的摘要，**不含**任何外部项目的内部细节。

请产出 **`out/d7-p0-1-adr-draft.md`**（**只写这一个文件**），内容分三节：

### 1. ADR 正文草案

把附件里那**三条可机械判定的分界判据**（`B-1` / `B-2` / `B-3`）写成一份 ADR 草案，含：
- **标题 + 状态**（状态写 `proposed`）；
- **上下文**：为什么需要"可机械判定的分界"（一两段）；
- **决定**：三条判据各一条，**判据原文照抄附件的表述**，不要改写其含义；
- **后果**：说明"用这三条复核既有归属项"这件事本身是怎么做的、结论是什么。

### 2. 灰色地带归属表

一张表，**逐项覆盖附件里列出的每一个灰色项**（一项一行，**不许合并、不许漏项**），列：
`灰色项 | 现状归属 | 裁定（留 D6 / 归 D7） | 依据哪条判据（写 B-1/B-2/B-3）`。
★ **每一项都要给出它命中的判据字母**；若某一项你**无法**从附件判出依据 ⇒ 该格写 `依据不足`（**不许猜**）。

### 3. `## 缺料与歧义（供裁定）`

逐条列出"要做这份草案、但**附件里没有**依据"的点（例如：需要某个数量、某个外部项目的具体机制、某条判据的适用范围）。
**没有**缺料就写一个字：`无`。

### 硬性要求

- ⚠ **不许补写附件里没有的内容**：附件是**摘要**，它不承载原文完整性；缺什么就写进第 3 节，**不要**用常识补齐。
- ⚠ **不要**引入任何外部项目名、仓库路径、主机名、IP、用户名；不要引用附件里没有的编号。
- 只写 `out/d7-p0-1-adr-draft.md` 这一个文件；不要读其它文件、不要探索目录。
