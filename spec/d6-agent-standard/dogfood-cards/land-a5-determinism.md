## 判据定义

**(a) 确定性**：同一输入、同一环境、同一版本代码连续执行两次，所有生成物逐字节一致（SHA-256 相等）。
**(b) 幂等性**：在确定性成立前提下，第二次运行不产生任何文件系统副作用（mtime、inode、目录项均不变），或仅产生与首次运行逐字节一致的覆盖写入。

## 双跑与比较

- **快照对象**：流水线声明的所有产出路径（文件/目录树），**排除临时目录**。
- **第二次运行**：在**相同工作目录、相同环境变量、固定随机种子**（若依赖 RNG）下直接再跑一次；不要求干净环境，但需保证首次运行不留下影响二次运行的状态（如锁文件、增量缓存）。
- **比较方式**：逐文件 SHA-256；目录递归比对文件集合与每文件哈希。**不排序、不归一化换行符**——若需归一化，应在生产端固化，而非比对端妥协。

## 必须排除的噪声

| 噪声类别 | 理由 |
|---|---|
| 当前时间戳（ISO / epoch / 格式化） | 每次运行必变，与输入无关 |
| 运行 ID / UUID / ULID / 增量序号 | 进程级唯一，非输入确定 |
| 绝对路径（`/home/...`、`C:\...`、`/tmp/xyz123`） | 机器/用户/容器相关 |
| 临时目录名（`mktemp`、`tempfile.mkdtemp`） | 内核分配不可控 |
| 并发调度顺序导致的键序 / 日志行序 | 线程/进程调度非确定 |
| 环境变量 `HOSTNAME`、`USER`、`PWD`、`PATH` 顺序 | 运行上下文差异 |
| 文件系统 mtime/atime/ctime / inode | 元数据随写入时间漂移 |

## 假绿

1. **首次运行即失败/异常退出**，第二次未执行或执行路径不同 → 逐字节一致（均为空/均无产物），实则未验证正常路径。
2. **生成物被显式排除**（如忽略清单未列入） → 未参与比对，实则未检查。
3. **天然不可双跑的生成物**：一次性外部副作用（推送远端、发邮件、写数据库、申请证书、硬件烧录）。**必须在清单中显式标记 `determinism: n/a` 并给出理由**，禁止静默跳过。
