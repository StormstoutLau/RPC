## 任务描述

**背景（抽象）**：一个研究仓库有一条**晋升门**：一条"经验"要从**私有层**升到**共享层**，必须同时满足若干判据。

其中一条判据是 **"复发"**：该经验必须在**跨项目**或**跨特征**上**重复出现过**，才算够格分享。

**实现现状**：

- 原文只说了"**复发**"，**没有给出次数**；
- 本仓库为了把这件事变成可机读，**新设了一个显式字段**（记"复发次数"）—— 也就是说，
  **"多少次算复发"这个数，是仓库自己定的**；它已被标成**未验证**（`unverified`）。
- 仓库**目前还没有共享记忆层** ⇒ 这个 schema **从未被任何真实条目走过一遍**（实例 0 条）。

**要你分析的问题（文档自认未定）**：

> ★ **次数阈值是"新设"、未定。** 且该 schema **从未被真实条目走过一遍**。

### 同一份规范里相邻的事实（相关，供你推理；不要照抄）

- 该层有一条**结构性约束**（"**不得自审**"）：作证的人不能是产出这条经验的人。
- 该仓库的立场：**能被机判的才算判据**；且它对"新设的数值阈值"有一条成见 ——
  **数值本身若没有校准依据，就只是"看起来精确"**。

### 唯一产物：`out/ud5-recurrence-threshold.md`

**格式（小节名照抄、顺序照抄）**：

1. `## 事实认定` —— 逐条（每条一行 `- `）写：你认定的事实 / 依据（上面哪条）/ 还不确定的。
   必须回答：**"阈值新设 + 零实例"这组事实的真正风险面是什么**？—— 是「**数值被当成已校准而使用**」·
   「**新设字段被当成既有事实**（后来者以为它是原文就有）」· 还是「**零实例 ⇒ 任何阈值都是空转，判据形同虚设**」？
   **三者可多选**，但每选一个必须说清**它成立的触发条件**。
2. `## 候选处置` —— **穷尽**列出可选动作（**≥4 条**），每条一行：
   `动作 | 适用条件 | 它避免了什么 | 它引入了什么代价 | 可逆性（可逆 / 不可逆）`。
   至少覆盖：**把该字段标成"未校准"并在输出里显式携带该标记** ·
   **先积累实例再定阈值**（即：先用"可见性"而非"判定"来跑） ·
   **把阈值降级为"提示"（不参与自动判定）** · **裁"不做"，并把该项登记为已知边界 + 再触发条件**。
   ★ 并**逐条回答**：这个候选**是"纪律"还是"判据"**？（本仓库的判准：**能被机判的才算判据**）
3. `## 决策` —— 选**一个或一个组合**，写：① 为什么（不要只说"稳妥"）；
   ② **它在什么情况下应被推翻**（反转条件，要**可判**）；
   ③ ⚠ **它会不会把真信号洗掉** —— 具体地：若"阈值只作提示不作判定"，
   **会不会让"本该被挡住的低复发经验"静默升层**？必须说明如何避免。
4. `## 可执行步骤` —— **有序**清单（每条一行 `- `），每条写：
   动作 / 期望输出 / 判据（看到什么算过）/ 不过怎么办。
   要求：**先取证、再判定、最后才动实现**；并写明"**动实现之前必须先留下什么记录**"。
5. `## 验收判据` —— 可机判形态 **≥3 条**（每条一行 `- `）：`看到 X ⇒ 判 Y`。
   **至少含一条反向**判据（"若出现 Z ⇒ **必须判不通过**"）。
   ★ 至少一条要能区分「**阈值作为判定**」与「**阈值仅作提示**」这两种形态。
6. `## 不确定项` —— 你无法从上述材料判定的，逐条说明缺什么（**不许猜**）。
