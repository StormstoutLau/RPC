## 任务描述

**背景（抽象）**：一个研究仓库对"**记忆面**"（长期记忆 / 笔记的读写通道）设了**四道门**（写入门 / 取回门 / 晋升门 / 复用门）
+ 一条**授权边界**（把"私有 → 共享"那一跳挡住）。门是否齐全、边界是否成立，由一条**检查项**判；
该检查项同时报出：**引擎侧无门的通道 1 条**（点名了一条"平铺笔记"通道）⇒ 现处置 = **点名 + 警告级**。

**要你裁的事**：一条**拆解方案**已产出（下面摘要）。现在要决定的是 **它怎么落进"目标档"** ——
即"记忆面门禁"的那份**单一真值表**及其**沿革记录**。你做**落法决策**，不是重写方案。

### 目标档的结构（**单一真值**，照此落，不得另造一份）

- `bridges[]` —— 每条通道登记：`isolated`（是否**按项目隔离**，实测口径）/ `gate`（取值 ∈ `cwd-keyed` / `by-design-shared` / `none`）/
  `controllable_by_us`（本仓能不能关）/ `why`（`by-design-shared` **必须**给）/ `evidence`。
- `structural_constraints[]` —— 每条：`judged_by`（**有判据才算结构**）/ `why_structural`（**必填**）/ `on_violation`。
- `unverified[]` —— 未核项。

**档内纪律（原文要点）**：`gate: none` + `controllable_by_us: true` ⇒ **红**（本仓能关却不关）；
`none` + `false` ⇒ **点名 + 警告级**（本仓关不了；**不许静默**）；`by-design-shared` ⇒ **必须给 `why`**。
**检查项的边界**：它**不阻断**、也**验不了门的效力** ⇒ "点名 + 警告级" **不等于**"已防护"。

**另有两条本仓纪律（与本题直接相关）**：
① 「**隔离靠文本前缀 ⇒ 红**」（即"靠命名约定当判据"是病，要靠**结构** contain）；
② **不造第二份真值** —— 同一事实只在**一处**写真值，其余地方只放**指针**；且该表**新增条目必须有 `why` + `evidence`**（只减不增式维护）。

### 待落方案（摘要；**不要照抄成结论**）

候选动作（括号内 = 成本 / 收益 / 副作用 / **是否只是把警告换个说法**）：

1. 什么都不做，但在**决策记录**里写下"引擎侧无门、不可控、接受残留风险"（纪律：「**不做也是一种结论，必须写下来**」）；
2. 在检查项输出里给该通道加"**引擎侧无门**"**专用标签**，并纳入**趋势观测**（让点位从一次性变成时间序列）；
3. 建**影子索引 + 定时比对告警**（发现未授权写入 ⇒ 人工复核）—— 属"**可观察但不可改**"；
4. 向上游/平台方**提需求**（要求引擎侧提供门扩展点：schema 校验 / 写入钩子 / 审计日志）—— 属"**不可控**"；
5. 给该通道文件加**前缀 / 改名**并声称"已隔离" —— **违反上面纪律 ①**，是**把警告换个说法**，不是防护。

推荐 = **2 + 1 + 3（视资源启动）**。
