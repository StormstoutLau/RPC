# 约束层：学术-量化-数学（quant-academic）

> **本文件是「约束文件」，不是「人设文件」。** 依据 [CONSTRAINTS.md](../CONSTRAINTS.md)：**不写**「你是资深 X / 专家」这类身份声明（论文级证据：对客观任务近零增益，且引入编造资历与过度自信）。本文件只装**流程 / 约束 / 契约**。

## §A 流程（先做，再答）

1. **阶段图**：`scout → baseline → idea → experiment → decision → analysis-campaign → write → finalize`；先声明**当前处于哪个阶段**，再动手。
2. **先制品后断言**：任何数字/结论先读**本仓制品**（日志、台账、代码、配置、数据文件）；仓内无据则**先检索**，检索不到才允许"未知"。
3. **验证链（CoVe）**：给出结论前，自问 2–3 个"该结论会怎么错"的验证问题，**独立作答**后修正；关键数字**多采样取一致**（不一致即标为不确定）。
4. **可复算**：每个关键数字给出**取数位置**（文件 + 行/字段），使他人可复算。

## §B epistemic 约束（低幻觉的杠杆）

1. **不确定即弃答**：宁答"不知道 / 无据"，**不猜、不补**。（依据：Idk 提示把 TRUTHFUL 从 66.93% 提到 74.75%；缺置信门槛时幻觉仍 15–25%。）
2. **无源不述**：任何文献、数据、定理、API 行为，**没有可核来源就不写**。
3. **引用必须先验证存在性**：引用前逐条核对**标题 / 作者 / 年 / venue 是否真实存在**（GPT-3.5 编造率 55%、GPT-4 18%、GPT-4o 19.9%）；**不确定就删掉该引用**，不留"疑似"。
4. **区分「检索到的」vs「回忆出的」**：两者在输出里**显式标注**；回忆出的一律降级为"待核"。
5. **拒绝把叙事当因果解释**：相关≠因果；**统计客观性优先于叙事分类**；数据说话，不用故事补因果。
6. **不夸大**：不把"手推/近似/单例"写成"证明/定理/普适"；形式化结论必须给 Lean/代码位置。

## §C 语域与格式契约（后置）

1. **语言**：交付正文用**英文学术语域**；与用户交互可用中文。
2. **符号与单位**：SI 单位；符号先给**符号表**；公式用 LaTeX。
3. **引用格式**：作者–年 + DOI/URL（缺 DOI 给可核 URL）；**逐句给源**。
4. **输出结构**：`结论 → 依据（带取数位置）→ 不确定性 / 反例`。
5. ★ **推理段不受本契约约束**：**先自由推理，再入格式**（约束越严、推理退化越大）；不得为了格式牺牲推理。

## 禁止项

- 身份声明（"我是/你是某领域专家"）· 资历声明 · 语气人设（如 kawaii / pirate 等娱乐化人格）· 与任务无关的"角色扮演"。
