## 设计文档章节骨架（含要写死的语义）

1. **背景与目标** — P3 在 P1/P2→P3→P4 阶梯的位置（引 §4 表 · O-141）。
2. **前置与射程** — 前置 = 形式化证明输入样本（`Auto_Prover` 现 0 条 · O-141 · `untested-index.yaml` L141 `U5#1`）；
   本件**零实现**；**逃逸如实写明**（见上）。
3. **AND-OR 超图 领域语义**（对齐 HTPS，arXiv:2205.11491「hypergraph / tactics as edges / subgoals as nodes」）
   - 节点身份 = **规范化 goal**（规范化串 / 其哈希）；根 = 待证定理 goal。
   - 超边 = **一条 tactic** 作用于某 goal ⇒ 产出 k 个子目标（**k≥0**；k=0 ⇒ 闭叶，该边直接证成该 goal）。
   - **AND** = **同一条超边**产出的 k 个子目标之间（**全证 ⇒ 该边证成父**）。
   - **OR** = 同一 goal 上的**多条**超边互为替代（**任一边证成 ⇒ 父证成**）。
   - 唯一判据（写死）：`proved(g) ⟺ ∃ e ∈ out(g) : ∀ c ∈ sub(e) : proved(c)`。
4. **依赖聚合与传播**
   - 节点态 = **封闭集** `{open, proved, failed, blocked}`；`blocked` = 被预算/超时/不可判挡住。
   - **自底向上、单调、确定、可复算**（同图重放 ⇒ 同状态）；聚合是**纯函数 `图 → 状态`**，与搜索**分离**。
   - `sorry` / 未闭合子目标 ⇒ 父**不得**为 `proved`（顶多 `blocked`）。
5. **verifier 闭环**
   - **Lean（compile / REPL）是唯一 oracle**；状态迁移**只在 oracle 判决后**发生。
   - **no-silent-success**：超时 / 异常 / 空输出 / 解析失败 ⇒ `unknown`（**判不了 ≠ 通过**）。
   - **执行器自报一律不可信**（本仓头号失效形态）。
6. **最简搜索策略** — 选 **best-first（优先队列）**。理由：**无学习价值函数**（HTPS 的 value function 我们没有），
   贪心在 AND-OR + 部分证明下易烧穿死分支。启发式**必须非学习型**：深度惩罚 + 子目标数惩戒 +
   复用 `Auto_Prover` 既有 `ErrorClassifier` 类别权重 + 是否近闭叶。**预算显式上界**（沿用 beam=4 / depth=10 / 最大扩展数）。
7. **与 `ProofNode/ProofTree` 的接缝契约** — **只许附加式**：现 `children: list`
   （`F:\Auto_Prover\proof_pipeline\datatypes.py` L590-655）= 无显式 AND/OR ⇒ 增设**显式超边**（edge 携带
   tactic + 其 k 个子节点引用）与 **OR 组**；**既有字段不动**。★ **RPC 内核不解析拓扑**（`ADR-0013` 护栏①）。
8. **漂移陷阱与「不做什么」** — 见下。
9. **未实测登记** — 见下。
10. **交叉引用** — `ADR-0013` L191-225 · O-141 · 调研 §2.3.1 / §4 · `untested-index.yaml` L141。
